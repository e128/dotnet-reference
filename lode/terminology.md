# Terminology
*Updated: 2026-11-21T20:39:46Z*

- **CPM**: Central Package Management. NuGet feature where all package versions are declared in `Directory.Packages.props` rather than per-project.
- **ReferenceTrimmer**: Analyzer and MSBuild task that reports a removable `Reference`, `ProjectReference`, or `PackageReference`. The build runs it through a `GlobalPackageReference` in `Directory.Packages.props`.
- **MTP**: Microsoft Testing Platform. The modern test execution platform used by xUnit v3, replacing the legacy vstest runner.
- **Cobertura**: An XML code coverage report format. The MTP coverage extension emits one Cobertura file per test module. See `lode/dotnet/code-coverage.md`.
- **Lode**: Structured AI-owned markdown repository for persistent project knowledge. Lives in `lode/`.
- **instructions**: The opencode config field that lists ambient instruction files or globs. opencode merges each file with `AGENTS.md`. `opencode.json` names `prompts/SystemPrompt.txt` and `.claude/rules/*.md`.
- **Plan**: A structured planning document set (`{name}-plan.md`, `{name}-context.md`, `{name}-tasks.md`) that lives in `plans/{name}/`.
- **TDD**: Test-Driven Development. Red-Green-Refactor cycle.
- **Verified Baseline**: A test case with `verified_baseline: true` in the registry. It passed at least once, so a later failure is evidence of a regression. See [TDD Regression Tracking](infrastructure/tdd-regression-tracking.md).
- **Confirmed Regression**: A failing test with a verified baseline, a changed production file, and an assertion or behavior failure. The only classification that appends a `caught` ledger event.
- **Unverified Red**: A failing test without a verified baseline. This is the normal Red phase of a new test, not evidence of a regression.
- **Harness or Environment Error**: A compilation, import, assembly, mock, fixture, timeout, or test-only failure. Also a verified failure with no production change.
- **Regression Ledger**: The append-only JSONL file `.tdd/regression-catches.jsonl`. It records `caught` and `resolved` events.
- **STE**: Simplified Technical English (after ASD-STE100). The repo's writing standard for docs, READMEs, PR bodies, error messages, comments, and lode files. Rules live in `.claude/rules/writing-style.md`.
- **Roslyn Analyzer**: A .NET compiler extension that provides real-time code analysis and diagnostics. This project ships `E128.Analyzers`, a custom analyzer package. Its rules span several categories, such as design, performance, reliability, security, and style.
- **MCP**: Model Context Protocol. An open protocol that exposes tools, prompts, and resources to an AI client. This repository connects the Roslyn Navigator server over stdio. See `lode/infrastructure/roslyn-navigator-mcp.md`.
- **Roslyn Navigator**: The `cwm-roslyn-navigator` .NET tool. It loads the solution with Roslyn and answers structural code questions over MCP. See `lode/infrastructure/roslyn-navigator-mcp.md`.
- **ArchUnitNET**: Architecture testing library for .NET. Used in `tests/Architecture.Tests/` to enforce project boundaries, layer dependencies, naming conventions, and sealed-class policies.
- **Trusted Publishing**: OIDC-based NuGet publishing. The `publish.yml` workflow authenticates to NuGet via OIDC rather than long-lived API keys.
- **OIDC**: OpenID Connect. The token protocol behind Trusted Publishing. It exchanges a short-lived token for a publish credential instead of a stored API key.
- **Renovate**: Dependency management bot. Configured in `renovate.json` to group updates, auto-merge patch/minor, and flag majors for review.
- **Kestrel**: ASP.NET Core's cross-platform web server.
- **NativeAOT**: Ahead-of-time compilation with the ILC toolchain. The output is a native binary with no JIT. `Directory.Build.props` applies its defaults when a project sets `PublishAot`. See `lode/dotnet/performance.md`.
- **TFM**: Target Framework Moniker. A string that names a project's target runtime, for example `net11.0` or `netstandard2.0`.
- **Diagnostic ID**: The `E128xxx` number assigned to each custom analyzer rule, for example `E128064`. The `E128.Analyzers` README lists the full rule table.
- **YAGNI**: You Aren't Gonna Need It. A principle that balances SOLID. Build an abstraction only when the code needs it now, not for a hypothetical future need.
- **TOCTOU**: Time-Of-Check To Time-Of-Use. A race condition where a file changes between a check and a later use. Analyzer `E128056` flags this pattern.
- **FIPS**: Federal Information Processing Standards. A cryptography compliance target. The rules E128071, E128075, and E128142 to E128151 enforce the policy. The container's stock Ubuntu Resolute OpenSSL package ships no FIPS provider.
- **gitleaks**: An open source secret scanner. `scripts/internal/precommit.sh` runs it on the staged diff, and the CI `lint` job runs it on the full history. See `lode/infrastructure/secret-scanning.md`.
- **Deterministic Script**: A `scripts/*.sh` wrapper that replaces an ad hoc command with a repeatable, token-free operation. See `.claude/rules/deterministic-scripts.md` for the full routing table.
- **Shell Lint**: The check over tracked shell scripts. `scripts/lint-shell.sh` owns it. See [Shell Authoring](infrastructure/shell-authoring.md).
