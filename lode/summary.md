# E128.Reference Summary
*Updated: 2026-11-19T20:37:01Z*

E128.Reference publishes the NuGet package E128.Analyzers. It is also a .NET 11 reference repository with modern conventions. The conventions cover custom Roslyn analyzers with code fixes in `src/E128.Analyzers/`, a minimal API web app (Kestrel), and a System.CommandLine CLI. The container images build with Podman on Ubuntu Resolute. The solution uses strict deny-by-default code analysis with third-party Roslyn analyzers (see `Directory.Packages.props`). Tests use xUnit v3 and Microsoft Testing Platform with in-process Cobertura coverage and an 80 percent line floor per assembly. ArchUnitNET architecture tests enforce structural invariants through IL analysis. `benchmarks/` holds BenchmarkDotNet starter benchmarks. Dependencies use Central Package Management with transitive pinning and Renovate. OIDC trusted publishing ships to nuget.org from GitHub Actions. The repository also carries a portable `AGENTS.md` instruction set and a Claude Code harness layer. `CLAUDE.md` imports `AGENTS.md`, rules, hooks, skills, and agents. Bash scripts power the harness. It tracks test provenance and TDD regressions in a registry and an append-only ledger through `scripts/tdd-track.sh`. See `lode/infrastructure/claude-code-maintenance.md` for the portable-versus-Claude-only capability map. See `lode/infrastructure/tdd-regression-tracking.md` for the regression method.
