# E128.Reference — Summary
*Updated: 2026-08-15T19:16:12Z*

E128.Reference is the source repository for the published NuGet package E128.Analyzers, and a .NET 10 reference repository demonstrating modern conventions: custom Roslyn analyzers with code fixes (E128.Analyzers, published to nuget.org from `src/E128.Analyzers/`), minimal API web app (Kestrel), System.CommandLine CLI, hardened, Podman-built container images (Ubuntu Noble base), strict deny-by-default code analysis with third-party Roslyn analyzers (see `Directory.Packages.props`), xUnit v3 + Microsoft Testing Platform, ArchUnitNET architecture tests enforcing structural invariants via IL analysis, Central Package Management with transitive pinning, Renovate for automated dependency updates, OIDC trusted publishing to nuget.org via GitHub Actions, and a portable `AGENTS.md` instruction set plus a Claude Code harness layer (`CLAUDE.md` imports `AGENTS.md`, rules, hooks, skills, agents) powered by bash scripts. See `lode/infrastructure/claude-code-maintenance.md` for the portable-versus-Claude-only capability map.
