# Delete Comment

Source comments are not allowed in `src/`. This skill repeats the migration that produced [Decision Records](../../../lode/decisions/summary.md).

## Procedure

1. Confirm the target path. The default is `src/`.
2. Run `scripts/comment-scan.sh --list` to list every offending line.
3. Group the lines into contiguous blocks. One block is one comment paragraph.
4. Read the surrounding code for each block. Do not trust the comment text.
5. Classify each block with the table below.
6. Write every Decision entry into `lode/decisions/`. Add a section per type.
7. Delete every comment block, including the Excuse blocks. Keep `///` doc comments.
8. Record each Excuse in the pull request body with its file and line.
9. Run `scripts/format.sh --changed`, then `scripts/check.sh`.
10. Run `scripts/comment-scan.sh --init` to record the remaining counts.

## Classification

| Verdict | Test | Action |
| --- | --- | --- |
| Tautology | The comment repeats the identifier, signature, or control flow | Delete |
| Stale | The comment contradicts the current code or names removed code | Delete |
| Excuse | The comment makes a shortcut look intentional | Delete and report |
| Decision | The comment states a constraint the code cannot show | Move to `lode/decisions/` |

A Decision entry earns its place when a future editor could break the code without it.
Signature-level prose on a private helper is a Tautology, not a Decision.

## Ratchet

`comment-baseline.txt` holds the per-file count that `scripts/comment-scan.sh` allows.
`--init` writes the current counts. A later cleanup runs `--init` again and lowers them.
Never raise a count without a stated reason in the pull request.

## Guardrails

- Keep a comment that justifies a `#pragma warning disable`. E128047 requires it.
- Keep a `// <auto-generated>` marker.
- Never edit a generated tree under `.opencode/`.
- Do not delete a comment that a code generator emits.
- Run the full gate after the last deletion. A passing build with no tests proves nothing.

## Report

Give the four verdict counts, the number of comment lines removed, and the Excuse list.
