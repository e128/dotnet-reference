# Write Clear Cross-References

Link to useful context with concise labels and precise destinations.

Keep enough explanation on the current page for readers to understand the subject. Use a link when it adds useful detail or points to an authoritative source.

## Choose and Label Links

- Use each destination once unless distance, page length, audience, or a specific section makes another link useful.
- Choose the most relevant page and the exact heading when it helps.
- Use a short, distinct label that makes sense out of context. Name the topic early in a descriptive label.
- Use the destination title or a short description. Do not reuse one label for different destinations.
- When a label includes an abbreviation and its full name, include both in the link text.
- For a code item, identify its role in the link text when that helps readers.
- Do not use vague labels such as “click here” or “this document.” Do not use a bare URL as link text.
- Explain why a separate reference matters. Use a consistent sentence such as “For more information about X, see Y.”
- Use a page or heading title when it helps readers identify the target.
- Use a site-root-relative path for internal website links. Use relative paths for links between repo files.
- Use secure URLs for external sites when they support them.
- Repeat a destination only when page length, distance between references, audience, or a specific section makes it useful.
- Keep punctuation outside the link when practical. Do not put linked cross-reference text in quotation marks.
- For an unlinked reference, use quotation marks for a section or short work. Use italics for a full-length work.

## Explain Link Behavior

- Say when a link downloads a file or starts an email.
- Say when a link moves to another section of the current page.
- Keep links in the same tab by default. Explain when a link opens a new tab.
- Make a move to another site clear when that context matters. Do not use an icon alone to signal the change.
- Keep documentation navigation within its documentation set when possible.

Source: [Google guidance on cross-references](https://developers.google.com/style/cross-references).
