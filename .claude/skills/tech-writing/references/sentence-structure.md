# Structure Sentences

Put conditions and goals before the actions that depend on them.

Lead with information readers need to decide whether an instruction applies. Then state the action or result.

## Lead With Purpose or Condition

- Introduce a reference with its purpose before its link.
- Put the goal before the action. For example, state why a reader deletes a document before naming the Delete control.
- Put a relevant condition before its outcome or instruction.
- For procedures, use the project's procedure rules as well as this sentence guidance.

## Examples

Write “To remove the entire document, select Delete.”

When an instruction applies only to specific regions, name those regions before describing the effect.

Source: [Google guidance on sentence structure](https://developers.google.com/style/sentence-structure).
