# Describe Reference Methods

Describe a method's documented action in third-person present tense.

Reference descriptions tell readers what a method does. They are not instructions to the developer.

## Use Third-Person Present Tense

Use a verb that agrees with the method as its subject. For example: `tasks.insert` creates a task on the specified task list.

Do not start a method description with an imperative verb. Write “Creates a task,” not “Create a task.”

Use the API's reference conventions for required punctuation and link formatting.

Source: [Google guidance on reference verbs](https://developers.google.com/style/reference-verbs). Related context: [Google Cloud API method descriptions](https://cloud.google.com/apis/design/documentation#method_description).
