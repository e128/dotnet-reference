# Images and Alt Text

Rules for figures, screenshots, alt text and captions.

## Choose the Format

- Use text, not an image of text, code or terminal output.
- Save diagrams as SVG or PNG, with no transparent background. Use MP4, not animated GIF.
- Hide personal data with a solid opaque overlay. Do not blur it.
- Use a diagram when a flow, structure or comparison reads better as a picture. Add text for the context a picture cannot carry.
- Keep text inside an image brief, in sentence case. Use numbered callouts instead of long annotations.

## Write Alt Text and Captions

- Alt text is 155 characters or fewer, a full sentence or noun phrase, with punctuation.
- Do not start alt text with "Image of" or "Photo of". Use `alt=""` for a decorative image.
- Do not use a caption in place of alt text. Put a long description in the surrounding text.
- Write a caption as a complete sentence with end punctuation. Refer to "figure 1" in lowercase, and never to "the image above".
- Introduce an image with a complete sentence that ends in a colon or a period.

Source: [Google guidance on images](https://developers.google.com/style/images).
