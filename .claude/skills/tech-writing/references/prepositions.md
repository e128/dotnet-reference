# Use Prepositions Clearly

Choose natural prepositions that make relationships easy to understand.

Do not rewrite a clear sentence only to avoid ending it with a preposition. Remove prepositions that add no meaning and revise clusters that make a sentence hard to read.

## Use Natural Word Order

Write “See the client library documentation for the language you use.” Avoid the less natural “the language with which you interact.”

Use a preposition when it clarifies a relationship. For example, describe when an icon changes color and when the connector appears.

For interface instructions, use the preposition that matches the control and action. Check the relevant interface guidance.

Source: [Google guidance on prepositions](https://developers.google.com/style/prepositions).
