# Lists, Procedures, and Notices

Rules for lists, procedures, paragraphs, notices, examples, footnotes and emphasis.

## Paragraphs

- Put the critical information first. Keep each paragraph to one idea and no more than five or six sentences.
- Prefer shorter sentences over fewer paragraphs.
- Left-align text. Do not force line breaks inside a sentence.

## Lists

- Use a numbered list for a sequence, a bulleted list for items without order, and a description list for term and definition pairs.
- Introduce a list with a complete sentence: "Use the Submit button for any of the following purposes:".
- Never make a one-item list. Keep items parallel.
- Capitalize the first letter of each item. End an item with a period when it is a sentence. A single word or code-only item takes no period.
- Avoid "etc." and "and so on".

## Procedures

- Write numbered steps as complete imperative sentences.
- Order each step as location or condition, then goal, then action: "To start a new document, click **File > New > Document**".
- Put an action and its result in one step: "Click **Run**. The results appear after the query runs."
- Number sub-steps with lowercase letters. Mark an optional step with the prefix "Optional:".
- Do not say "please", "above" or "below". Do not list keyboard shortcuts. Do not make a one-step numbered list.
- Link to a procedure that already exists instead of repeating it.

## Notices

- Note: relevant but not required for success. Caution: proceed with care. Warning: risk of an irreversible outcome.
- Do not put required information, prerequisites or a full step in a notice.
- Use notices sparingly, and never stack two in a row.

## Examples, Footnotes and Emphasis

- Introduce a short example in parentheses with "for example,". Introduce a long one as its own sentence that starts "For example,".
- Avoid footnotes. Use a cross-reference, a note or a parenthetical.
- Italicize a new term when you define it, and a word used as a word. Do not use bold or quotes for either.
- Use bold for UI elements and run-in headings only. Do not use bold or italics for emphasis. Underline only link text.
